Backport of the latest `master` web viewer onto the `prq49` branch simulation code.

The page (`index.html`, `includes/`, `keys.toml`, `custom.css`, `make_html.py`) is generated from `master` `web/` sources.

The compiled executable (`dishtiny*.js`, `dishtiny*.wasm`, `dishtiny.worker.js`) is built from the `prq49` branch (`978abb3e`) with the viewer code taken from `master` (`fa5d960f`).
`source.patch` is the full source diff against `prq49`; apply it with `git apply` on a `prq49` checkout to reproduce the build.
`source.tar.gz` is the complete source tree used for the build, including all third-party submodule sources, without `.git` metadata or the emsdk toolchain.
To rebuild from it, install emsdk 2.0.5 with the liblzma port patch at `third-party/emsdk` (see `third-party/install_emsdk.sh`), then run `make dishtiny.js dishtiny-no-pthread.js CXXFLAGS="-DDISH2_SPEC=dish2::Spec_prq49 -DDISH2_NLEV=2"`.
Without `.git` metadata, the embedded source hash string differs from the shipped build.
The emscripten-ports zlib `version_1` archive GitHub serves no longer matches emsdk 2.0.5's pinned hash; the shipped build used a zip of that tag made with `git archive --prefix=zlib-version_1/`, with the hash in `tools/ports/zlib.py` updated to match.
The patch:

* replaces `include/dish2/web/`, `include/dish2/viz/`, `source/web.cpp`, and `web/` with their `master` versions;
* adds `master`'s `include/dish2/web_utility/` and four `master`-only helper headers the viewer needs (`utility/save_text.hpp`, `introspection/get_live_cardinal_kin_group_ids.hpp`, `introspection/get_live_cardinal_root_ids.hpp`, `cell/cardinal_iterators/RepLevRequestWrapper.hpp`);
* calls `prq49`'s non-template `dish2::setup` from `source/web.cpp`;
* re-enables the Population Loader panel (commented out on `master`), listing only the bundled genomes, generated by `web/make_population_loader.py`;
* ports `master` commit `1f5f3699` ("Disable RootIDChangeoverRecorder for web"), also applied to `prq49`'s `multiculture_population.hpp`, since the recorder aborts when seeding a population in the browser (it only logs root ID changeovers and does not affect simulation dynamics);
* uses `master`'s `Makefile` for its web build flags (`-idirafter third-party/mpi-abi-stubs/`, growable memory for the no-pthread build).

All other simulation code is unchanged from `prq49`.
The build uses `dish2::Spec_prq49` and `DISH2_NLEV=2`, as in `configpacks/bucket=prq49+*/build_web.sh`, with emsdk 2.0.5 plus the liblzma port patch from `third-party/install_emsdk.sh`.
`Spec_prq49` matches `prq49`'s `Spec_default` apart from names and comments.

Features carried over from `master` include the newer viewers (including the register viewers and stint root viewer), PNG render saving, the "Download Saved" zip bundle, and the data output (`a=saved+what=dishtiny+ext=.jsonl.gz`).

`genomes/` bundles wildtype genomes from every available stint of series 16005 (thread 0, endeavor 16) from the `prq49` S3 bucket.
Focal strain genomes (`criteria=abundance`, from `genomes/stage=0+what=generated/`) cover stints 0 through 100.
Coevolved background strain genomes (`criteria=abundance_highest_root`, from `genomes/stage=1+what=extracted/`) cover stints 0 through 100.
These are the same genome pairs the `prq49` `lowestandhighestroot-multiculture` jobs seed together.
The Population Loader has three sections of per-stint buttons: focal strain monocultures, background strain monocultures, and multicultures that autoinstall both same-stint genomes.
`genomes/a=genome+ext=.json.gz` is the stint 100 focal strain genome, kept so earlier links keep working.

All links to this viewer pass the config overrides `COLLECTIVE_HARVEST_RATE=0%090.25&GROUP_EXPIRATION_DURATIONS=0%091024&OPTIMAL_QUORUM_COUNT=0%0912&P_QUORUM_CAP_KILL=0%090.0825&P_SET_QUORUM_BIT=0%091&QUORUM_CAP=0%0936&N_CELLS=900`.
For example, <https://mmore500.com/dishtiny/prq49-backport/?COLLECTIVE_HARVEST_RATE=0%090.25&GROUP_EXPIRATION_DURATIONS=0%091024&OPTIMAL_QUORUM_COUNT=0%0912&P_QUORUM_CAP_KILL=0%090.0825&P_SET_QUORUM_BIT=0%091&QUORUM_CAP=0%0936&N_CELLS=900>.

To regenerate the Population Loader, run `python3 web/make_population_loader.py path/to/genomes` and then `python3 web/make_html.py` from the source tree root.
